# NMDP Berkeley — GitHub Pages edition

This folder is a static, GitHub Pages-ready version of the NMDP awareness website.

## Publish

1. Create a public GitHub repository named `unroll-hope-berkeley`.
2. Upload everything in this folder to the repository root.
3. In **Settings → Pages**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`, then save.

## QR tracking

Create the Bitly QR Code with this destination after GitHub Pages provides the final URL:

`https://YOUR-GITHUB-USERNAME.github.io/unroll-hope-berkeley/?utm_source=qr&utm_medium=poster&utm_campaign=nmdp_berkeley`

Use a different `utm_content` value for each physical location, such as `utm_content=amazon_hub`.
